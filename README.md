# payments-reconciliation-dbt

An end-to-end payments reconciliation on Google Cloud. A payment provider's daily settlement files are matched against a company's own payment records across five currencies, and every payment gets a status: matched, pending, missing, duplicate, late, amount mismatch, FX mismatch, or unrecorded.

```
data/ (generated CSVs) -> Cloud Storage -> BigQuery (payrecon_raw) -> dbt (payments_recon) -> marts
```

Work in progress, built in public. See:

- [Project plan](docs/project-plan.md): the business problem, design, matching rules, tests and schedule
- [Setup](docs/setup.md): bucket, datasets, loading and dbt, step by step
- [Data dictionary](docs/data-dictionary.md): every file and column
- [Learning resources](docs/learning-resources.md): what to watch and read, week by week

All data is generated by [`generator/generate_data.py`](generator/generate_data.py) for a fictional company. None of it comes from a real business.
